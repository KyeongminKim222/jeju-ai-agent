1. 문제 정의

도민이 “여기서 장사해도 되나”, “어디 가야 덜 붐비나”를 말로 물으면, 제주데이터허브 데이터로 근거 있는 답(등급·숫자·그래프·출처)을 돌려준다. 공개 데이터는 있지만 가공 장벽 때문에 도민이 쓰지 못하는 문제를 Agent로 해결한다.

2. Agent 구조

언어모델(qwen2.5:3b, 로컬)은 질문 이해만 맡고, 숫자는 결정적 분석 도구가 계산한다. 언어모델 결과는 규칙·사전으로 재검증한다.

3. 실행 결과

예시 1 — 애월에 카페 하나 차리면 괜찮수과?

① 질문 이해LLM(qwen2.5:3b)+규칙 검증 → 도구=diagnose, 지역=애월읍, 업종=카페
② 값 확인·보완모든 값이 질문에 있음
③ 도구 실행diagnose(애월읍, 카페) — 같은 업종 38개 읍면동과 6개 지표 비교
④ 후속 도구 자동 호출등급 E → alternatives(카페) 로 더 안전한 동네 3곳 탐색
④ 후속 도구 자동 호출area_tour_season(제주시 서부) — 주변 관광지 계절 흐름 확인
⑤ 답변 생성·검증템플릿
애월읍 카페 창업 위험도는 E등급(높음)입니다. 같은 업종을 하는 제주 38개 동네 중 30번째로 안전합니다(점수 34점/100). 이 동네 카페 전체 카드매출은 평상시 한 달 5,268만원인데, 가장 어려운 11월에는 3,703만원으로 줄어듭니다. 2020년 봄 같은 큰 충격이 오면 4,431만원 수준까지 떨어졌습니다. 약점은 최근 성장세가 약함, 성수기·비수기 차이가 큼이고, 강점은 주민 수요가 탄탄함입니다. 현재 이 동네 카페 점포는 228곳입니다. 같은 업종으로 위험이 더 낮은 동네: 이도2동(A등급), 노형동(B등급), 일도2동(B등급).

예시 2 — 연동에서 한식당 하면 장사 될까요

① 질문 이해LLM(qwen2.5:3b)+규칙 검증 → 도구=diagnose, 지역=연동, 업종=한식당
② 값 확인·보완모든 값이 질문에 있음
③ 도구 실행diagnose(연동, 한식당) — 같은 업종 43개 읍면동과 6개 지표 비교
④ 후속 도구 자동 호출area_tour_season(제주시 시내) — 주변 관광지 계절 흐름 확인
⑤ 답변 생성·검증템플릿
연동 한식당 창업 위험도는 B등급(다소 낮음)입니다. 같은 업종을 하는 제주 43개 동네 중 9번째로 안전합니다(점수 66점/100). 이 동네 한식당 전체 카드매출은 평상시 한 달 28.2억원인데, 가장 어려운 2월에는 24.3억원으로 줄어듭니다. 2020년 봄 같은 큰 충격이 오면 21.5억원 수준까지 떨어졌습니다. 약점은 외부 충격 때 매출이 크게 빠짐, 최근 성장세가 약함이고, 강점은 매출이 달마다 고른 편, 계절을 덜 탐입니다. 현재 이 동네 한식당 점포는 613곳입니다.
